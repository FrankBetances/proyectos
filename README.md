# Valeria+ Web · Sitio Informativo y de Presentación

Sitio web oficial de presentación para **Valeria+** (Terapia auditivo-verbal y del lenguaje offline para niñas y niños con hipoacusia, implante coclear, dislalias, TEA o dislexia).

Construido con **Astro**, **TypeScript** y un sistema de diseño CSS en modo oscuro.

## 🚀 Despliegue en GitHub Pages

Este repositorio se despliega automáticamente en GitHub Pages mediante GitHub Actions en:
👉 **[https://FrankBetances.github.io/valeria-web/](https://FrankBetances.github.io/valeria-web/)**

## 💻 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
