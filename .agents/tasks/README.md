# Sistema de Gestión de Tareas

Esta carpeta (`.agents/tasks/`) está destinada a almacenar los artefactos y registros de tareas (ej. `task.md`, `implementation_plan.md`, `walkthrough.md`) que genera el asistente IA durante la resolución de problemas.

## Reglas para el Asistente:
1. **Historial de Ejecución**: Siempre que se planifique un rediseño, una nueva característica o un cambio estructural, el asistente debe generar un archivo de tareas aquí para registrar el progreso.
2. **Cierre de Ciclo**: Una vez finalizada la tarea y completado el despliegue automático, el asistente debe dejar un documento de `walkthrough` resumiendo las acciones tomadas para futuras referencias.
